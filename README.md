# AI-Readiness-Investment-SEA

This repository contains the analysis behind my article on the relationship between AI readiness and subsequent private AI investment, with a particular focus on Southeast Asia.

I use the Oxford Insights Government AI Readiness Index (2023) and Stanford AI Index / Quid private investment data (2024). The analysis covers 59 economies and looks at whether higher AI readiness is associated with greater private AI investment, including after controlling for GDP.

The analysis is observational and is intended to examine association rather than establish causality.

## Data

The main data sources are:
- Oxford Insights Government AI Readiness Index (2023)
- Stanford AI Index / Quid private AI investment data (2024)
- World Bank GDP data (2023)

The source data are not included in this repository. The notebook currently reads them from Google Drive, so the file paths would need to be updated to rerun it elsewhere.
